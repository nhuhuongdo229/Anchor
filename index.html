Problem statement

Live online classes run on a structure inherited from business meetings.

Meetings aim forefficiency

  • Finish fast
  • Stick to the agenda
  • One person talks
  • Others on mute
vs

Classes needengagement

  • Time to think
  • Room for questions
  • Everyone takes part
  • Talk with each other
Problem statement · who it affects

Students and teachers are left to manage on their own.

Students

Expected toPay attention all class
ButNothing helps them catch up

Teachers

Expected toKnow how the class is doing
ButCan't see who is following

The platform

Expected toHelp run the class

The audit

Zoom, Teams and Canvas each solve a piece.

Zoom

Video calls
Quick reactions, timed breakout rooms
  • Timer only on your own screen
  • No sign when attention leaves

Teams

Chat and meetings
Chat, files and recap stay with the class
  • Notifications stay on during class
  • Engagement data arrives after class

Canvas

Course pages
Announcements reach students right away
  • Lives before and after class
  • Nothing inside the live hour

The gap

Each one solves a piece. None of them run the live class.

Classes need one place that covers what's still missing: a plan everyone can see, check-ins, a way back, and a sense of the room.
